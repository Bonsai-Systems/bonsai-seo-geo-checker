BONSAI SEO/GEO CHECKER — LLM INSTRUCTIONS
=========================================

WHAT IT IS
Internal WordPress plugin by The Bonsai Digital Collective. It audits one URL for
technical SEO, meta, content, social, structured data, AI visibility (GEO) and
mobile performance (PageSpeed Insights), then asks Claude for a prioritised fix
list. Admin page: Tools > SEO/GEO checker. Capability: manage_options.
Version 1.0.0. WP 6.2+, PHP 7.4+. Prefix: bsgc / BSGC_.

FILES
bonsai-seo-geo-checker.php  bootstrap, constants BSGC_VERSION/PATH/URL
inc/class-bsgc-settings.php  ACF options sub-page + BSGC_Settings::get()
inc/class-bsgc-fetcher.php   wp_safe_remote_get wrapper (SSRF-safe)
inc/class-bsgc-robots.php    RFC 9309 robots.txt parser
inc/class-bsgc-analyser.php  all checks + score(); CATEGORIES, SEARCH_BOTS, TRAINING_BOTS
inc/class-bsgc-pagespeed.php PSI v5 mobile
inc/class-bsgc-ai.php        Anthropic Messages API, JSON fix list, sanitise()
inc/class-bsgc-reports.php   hidden CPT bsgc_report
inc/class-bsgc-admin.php     admin page + AJAX
assets/admin.js / admin.css  jQuery UI, print styles

AJAX ACTIONS (nonce "bsgc", manage_options)
bsgc_run_check, bsgc_run_pagespeed, bsgc_run_ai, bsgc_get_report, bsgc_delete_report

STORAGE (post meta on bsgc_report)
_bsgc_report (base checks), _bsgc_performance, _bsgc_ai, _bsgc_score (cache)
PSI and AI run in parallel, so each writes its own key. Do not combine them.

CHECK FORMAT
category, id, label, status (pass|warn|fail|info), message, weight, value
Score: pass = weight, warn = weight/2, fail = 0, info = unscored.

SETTINGS (constant overrides ACF option)
BSGC_ANTHROPIC_KEY / bsgc_anthropic_api_key
BSGC_PSI_KEY       / bsgc_psi_api_key
BSGC_CLAUDE_MODEL  / bsgc_claude_model  (default claude-haiku-4-5-20251001)
ACF fields are registered in PHP, so there is no acf-json folder.

RULES
- WordPress Coding Standards: tabs, Yoda conditions, escape all output.
- User-supplied URLs are fetched only through BSGC_Fetcher::get() (wp_safe_remote_get).
- JS inserts dynamic data with .text()/.attr(), never .html().
- Claude output must pass through BSGC_AI::sanitise().
- Never hardcode or log API keys.
- UK English in UI copy and prompts.
- Training crawlers are reported as info and never scored.
- Don't claim schema is missing based on static HTML alone. Refer users to
  Google's Rich Results Test.
- Update CHANGELOG.md and bump the version in both the plugin header and
  BSGC_VERSION for releases.
